# 基于 STM32 的超声波测距系统

基于 STM32F103 与 HC-SR04 的超声波测距系统。使用 TIM3 定时器输入捕获测量 Echo 回波脉宽，SSD1306 OLED 实时显示距离与调试信息。

河北工程技术学院 电子信息工程专业课程项目（2026.05 – 2026.06），团队作业。

## 功能

* HC-SR04 超声波测距，量程 3\~400cm
* TIM3 输入捕获测量回波脉宽（定时器 1MHz 计数，即 1μs 计数分辨率）
* SSD1306 OLED（128×64，GPIO 软件模拟 I2C）实时显示距离、帧计数与原始脉宽
* 异常状态可视化：无回波显示 `255`，超量程 / 超时显示 `200`，便于区分故障类型
* 实测：满量程误差 < 0.5%，测量周期约 60ms，长时间运行稳定

|PA6|HC-SR04 Echo|输入，TIM3\_CH1 输入捕获|
|?|OLED SCL|软件模拟 I2C|
|?|OLED SDA|软件模拟 I2C|

## 工作原理

1. `Trig\\\\\\\_OutUp\\\\\\\_15us()` 在 PB0 输出 15μs 高电平脉冲，触发 HC-SR04 发射超声波
2. Echo 引脚（PA6）随之输出高电平，高电平时长与障碍物距离成正比
3. TIM3 配置为 1MHz 计数（1μs 计数分辨率），CH1 输入捕获接在 PA6
4. **极性翻转法测量脉宽**——捕获中断里在上升沿与下降沿之间切换捕获极性（`TIM3->CCER` 的 `TIM\\\\\\\_CCER\\\\\\\_CC1P` 位）：

   * 上升沿：记录起始值 `Capture\\\\\\\_Rise`
   * 下降沿：`US\\\\\\\_Num = capture\\\\\\\_val - Capture\\\\\\\_Rise`，并处理 16 位计数器回绕
5. 距离换算：`Dis = US\\\\\\\_Num / 58`（58μs/cm，按声速往返折算）
6. 有效范围判断：`58`（3cm）\~ `23200`（400cm），超出则判为异常

## 本人负责的部分

本项目为 3–4 人课程小组完成，本人担任组长，负责：

* **HC-SR04 驱动**（`Hardware/HC-SR04.c`）：Trig 触发时序与 Echo 回波读取
* **SSD1306 OLED 显示驱动**（`Hardware/OLED.c`）：GPIO 软件模拟 I2C，实现距离、帧计数与原始脉宽的实时显示
* **TIM3 输入捕获模块的移植与调试**：配置定时器分频与捕获极性，调试到稳定运行。极性翻转这一技巧本身来自参考实现，本人的工作是把捕获逻辑移植进自己的工程并调通
* **部分电路搭建与系统联调**；作为组长协调各模块分工与进度

小组其他成员负责回波异常处理与分类判断逻辑、以及部分系统逻辑。
