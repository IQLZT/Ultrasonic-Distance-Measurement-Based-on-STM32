# 基于 STM32 的超声波测距系统

基于 STM32F103 与 HC-SR04 的超声波测距系统。使用 TIM3 定时器输入捕获测量 Echo 回波脉宽，SSD1306 OLED 实时显示距离与调试信息。

河北工程技术学院 电子信息工程专业课程项目（2026.05 – 2026.06），团队作业。

## 功能

* HC-SR04 超声波测距，量程 3\~400cm
* TIM3 输入捕获测量回波脉宽（定时器 1MHz 计数，即 1μs 计数分辨率）
* SSD1306 OLED（128×64，GPIO 软件模拟 I2C）实时显示距离、帧计数与原始脉宽
* 异常状态可视化：无回波显示 `255`，超量程 / 超时显示 `200`，便于区分故障类型
* **Proteus 仿真结果**：量程 3\~400cm，满量程误差 < 0.5%，测量周期约 60ms

|PB0|HC-SR04 Trig|输出，15μs 触发脉冲|
|PA6|HC-SR04 Echo|输入，TIM3_CH1 输入捕获|
|?|OLED SCL|软件模拟 I2C|
|?|OLED SDA|软件模拟 I2C|

## 工作原理

1. `Trig_OutUp_15us()` 在 PB0 输出 15μs 高电平脉冲，触发 HC-SR04 发射超声波
2. Echo 引脚（PA6）随之输出高电平，高电平时长与障碍物距离成正比
3. TIM3 配置为 1MHz 计数（1μs 计数分辨率），CH1 输入捕获接在 PA6
4. **极性翻转法测量脉宽**——捕获中断里在上升沿与下降沿之间切换捕获极性（`TIM3->CCER` 的 `TIM_CCER_CC1P` 位）：

   * 上升沿：记录起始值 `Capture_Rise`
   * 下降沿：`US_Num = capture_val - Capture_Rise`，并处理 16 位计数器回绕
5. 距离换算：`Dis = US_Num / 58`（58μs/cm，按声速往返折算）
6. 有效范围判断：`58`（3cm）\~ `23200`（400cm），超出则判为异常
